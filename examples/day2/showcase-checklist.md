# Slide 46 showcase checklist

- Start `npm run dev` with Chrome DevTools Console visible.
- Search for a product name using different letter cases.
- Filter by one category, then use both price directions.
- Add the same product twice and another product once; confirm cart count and total.
- Refresh and confirm the cart persists.
- Open product details, test Escape, and use keyboard controls in the cart.
- If demonstrating checkout, state clearly that it is demo-only and no payment is processed.
- Confirm there are no red Console errors during the demonstration.
